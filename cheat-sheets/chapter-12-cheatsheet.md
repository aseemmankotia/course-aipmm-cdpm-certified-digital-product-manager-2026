# Chapter 12 Cheat Sheet — Full Exam Simulation & Time-Management

## Pacing Table (~120Q / ~120min)
| Time Elapsed | Target Question # (60s/Q pace) |
|---|---|
| 30 min | ~30 |
| 60 min | ~60 |
| 90 min | ~90 |
| 110 min | ~110 (start final flag review) |
If you're >10 questions behind pace, speed up before touching flags.

## Two-Pass Technique
| Pass | Action |
|---|---|
| 1 | Answer confident Qs immediately; flag uncertain ones; never stall >90s on one item |
| 2 | Return ONLY to flagged Qs, using remaining time; lock a guess before time runs out |

## Keyword Signals
| Keyword | Signals |
|---|---|
| BEST / MOST appropriate | Judgment call among plausible options |
| FIRST | Sequencing — pick earliest correct step |
| CHEAPEST valid | Cost-constrained elimination — must still meet all requirements |

## Distractor Patterns
| Pattern | Why it's wrong |
|---|---|
| Too expensive/over-engineered | Solves problem but violates stated constraint |
| Doesn't meet all requirements | Satisfies partial scenario only |
| Deprecated/outdated approach | No longer valid practice |
| Right idea, wrong stage | e.g., automating before validating demand |

## Cross-Domain Framework Quick Reference
| Framework | Use When |
|---|---|
| JTBD (Functional/Emotional/Social) | Understanding underlying user motivation |
| MVP types (Concierge, Wizard of Oz, Landing Page, Single-Feature) | Choosing fastest validation method pre-build |
| AARRR (Acquisition→Activation→Retention→Referral→Revenue) | Diagnosing which funnel stage is failing |
| RICE (Reach×Impact×Confidence/Effort) | Feature-level scoring, no cost-of-delay data |
| WSJF (Cost of Delay/Job Size) | Flow-based/SAFe backlog, cost-of-delay varies |
| Kano (Must-be, Performance, Attractive, Indifferent) | Classifying feature impact on satisfaction |

## Fatigue Management
- Use micro-pauses (seconds, eyes off screen) — do NOT leave workstation/camera view unless platform allows scheduled breaks.
- Re-hydrate/posture-check only during any officially permitted break.
- Save hardest flagged items for the final review pass when re-energized by having cleared the rest.

## Final Review Checklist
1. All 120 questions have an answer selected (none blank).
2. Flagged items reviewed in order of confidence, lowest first if time allows.
3. Submit only after confirming no blanks remain.
