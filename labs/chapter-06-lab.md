# Chapter 6 Lab: Agile Delivery Fundamentals for Digital Products

**Estimated time:** 18 minutes

## Exercise

Given a raw feature request, write a user story with acceptance criteria that meets INVEST, add it to a mock backlog, and run a refinement pass identifying missing dependencies

## Key takeaway

The product owner owns backlog priority and value tradeoffs; the delivery framework (Scrum vs Kanban) is chosen based on the predictability of the work.
