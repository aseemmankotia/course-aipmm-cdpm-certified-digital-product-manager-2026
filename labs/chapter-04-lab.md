# Chapter 4 Lab: Lean Startup and Riskiest Assumption Testing

**Estimated time:** 20 minutes

## Exercise

Given a product concept brief, write a formal hypothesis, identify the single riskiest assumption using the desirability/viability/feasibility framework, and design the cheapest test that could invalidate it

## Key takeaway

Always test the riskiest assumption first, using the cheapest experiment that can genuinely invalidate it.
