# Chapter 10 Lab: UX Fundamentals, Accessibility, and Design Systems for PMs

**Estimated time:** 15 minutes

## Exercise

Review a provided screenshot of a checkout flow, identify two accessibility violations and one usability heuristic violation, and write a one-paragraph design partnership brief requesting fixes using design system components where possible

## Key takeaway

A digital PM partners on UX and accessibility decisions using design system components by default, escalating to custom design only when justified.
