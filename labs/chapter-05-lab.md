# Chapter 5 Lab: MVP Types and Experiment Design

**Estimated time:** 18 minutes

## Exercise

Given four different assumption scenarios, match each to the correct MVP type (concierge, Wizard of Oz, landing page, single-feature) and write the success metric that would validate or invalidate each

## Key takeaway

Select the MVP type by what assumption it must validate cheaply, never by how close it looks to the final product vision.
